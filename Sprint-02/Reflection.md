# Reflection – Salesforce Developer Bridge Program (Day 2)

## What Worked Well

Understanding Apex Collections and Bulkification significantly improved my approach to writing Salesforce code.

Processing multiple records using Lists, Sets, and Maps felt much more efficient than handling records individually.

---

## Most Interesting Part

The most interesting concept was Governor Limits.

Seeing how inefficient code can fail when processing many records helped me understand why Salesforce emphasizes Bulkification.

---

## Biggest Challenge

The biggest challenge was understanding how Maps simplify record retrieval and why SOQL queries should never be placed inside loops.

Understanding asynchronous execution using @future methods also required careful study.

---

## Lessons Learned

- Lists process multiple records.
- Sets remove duplicate values.
- Maps provide efficient record lookup.
- Governor Limits encourage optimized code.
- Bulkification is essential for enterprise Salesforce development.
- Long-running tasks should execute asynchronously.

---

## Future Improvements

If this project continued, I would:

- Learn Queueable Apex in depth.
- Explore Batch Apex for large datasets.
- Implement Trigger Frameworks.
- Practice Bulk Testing.
- Improve LWC communication patterns.
