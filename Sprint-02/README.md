
# Salesforce Developer Bridge Program – Day 2

## Project Overview

Day 2 focused on writing scalable Salesforce applications by introducing Apex Collections, Governor Limits, Bulkification, Asynchronous Apex, and Lightning Web Component communication.

The goal was to move from writing functional Apex code to writing production-ready Apex code.
