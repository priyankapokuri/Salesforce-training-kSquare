# Day 11 – Reflection

## What I Learned

This sprint helped me understand how multiple LWCs can work together as one application. I learned how to pass data from parent to child using `@api` and communicate from child to parent using Custom Events.

I also learned the importance of clear data ownership, client-side versus server-side validation, Lightning Data Service, reactive data, and reusable components.

## Key Takeaway

The main learning from this sprint is that good Salesforce development is not only about writing code, but also about designing components with clear responsibilities and communication.

## Improvement Area

I need to practise component communication, data refresh strategies, and choosing between LDS and Apex based on the requirement.
