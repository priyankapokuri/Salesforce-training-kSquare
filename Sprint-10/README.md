# Sprint 9 – Lightning Web Components (LWC)

## Overview

Sprint 9 focused on building interactive user experiences using **Lightning Web Components (LWC)** and connecting the Salesforce UI with the Apex and Service Layer developed in previous sprints.

The sprint covered LWC fundamentals as well as interactive business workflows for the **Student Placement Management System**.

---

## Topics Covered

- Lightning Web Component Structure
- HTML, JavaScript, and Metadata
- Data Binding
- User Events
- Lightning Data Service
- Wire Service
- Apex Integration
- Component Lifecycle
- Eligible Jobs Component
- Imperative Apex
- Apply Job Workflow
- Loading, Success, Empty, and Error States
- Parent-Child Communication
- Custom Events
- UI Refresh
- LWC Debugging

- Lightning Web Components (LWC)
