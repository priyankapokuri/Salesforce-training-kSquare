# Reflection – Salesforce Interview Readiness Bootcamp (Day 4)

## What Worked Well

Today's assignment helped me understand how Salesforce applications are presented to end users through Lightning Web Components.

Building my first interactive component made it easier to connect frontend development with the backend concepts I learned in previous days.

---

## Most Interesting Part

The most interesting concept was data binding.

Seeing the UI automatically update whenever a JavaScript variable changed demonstrated how responsive and interactive Lightning Web Components can be.

---

## Biggest Challenge

The biggest challenge was understanding the responsibilities of the three LWC files and how they work together.

Learning when to place code in HTML, JavaScript, or the Meta XML file required careful understanding.

---

## Lessons Learned

- HTML defines the user interface.
- JavaScript manages component behavior.
- Meta XML controls component deployment.
- Data binding keeps the UI synchronized with JavaScript variables.
- Event handling enables user interaction.
- LWC provides a clean separation between presentation and business logic.

---

## Future Improvements

If I continue enhancing this project, I would:

- Connect the component to Apex classes.
- Retrieve live Salesforce records using @wire.
- Display real placement statistics.
- Improve the UI using Salesforce Lightning Design System (SLDS).
- Create reusable child components.

---

## Today I Learned

> Lightning Web Components are not just user interfaces—they are reusable, interactive building blocks that connect Salesforce users with business logic in a clean and efficient way.

---

## Areas for Improvement

- Gain deeper knowledge of JavaScript in LWC.
- Practice @wire and imperative Apex calls.
- Build more interactive components.
- Learn parent-child communication.
- Improve UI design using SLDS.

---

## Sprint Summary

Day 4 introduced the frontend layer of Salesforce development through Lightning Web Components.

By combining HTML, JavaScript, and Meta XML, I built my first interactive user interface and understood how LWC integrates with Apex and Salesforce data.

This assignment marked the transition from backend-focused development to full-stack Salesforce application development.
